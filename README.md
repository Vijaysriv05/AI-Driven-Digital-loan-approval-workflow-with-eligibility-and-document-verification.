## 📖 Overview

**Nimbus Lending** is a modern, full-stack digital lending platform designed to streamline loan applications, automate eligibility scoring, and perform AI-driven document verification. 

It provides an intuitive experience for applicants to evaluate loan options, upload financial documents, track approval stages in real-time, and receive instant AI feedback on their eligibility.

---

## ✨ Key Features

- 📄 **AI Document Verification:** Parses and verifies uploaded bank statements, identity proofs, and tax documents using LLM OCR & verification pipelines.
- 📊 **Automated Eligibility Scoring:** Computes credit eligibility scores dynamically based on income, credit rating, and financial liabilities.
- ⚡ **Real-Time Loan Tracking:** Interactive dashboard for applicants and administrators to monitor application progress from submission to disbursement.
- 🛡️ **Role-Based Authentication:** Secure JWT-based authentication supporting Applicants and Underwriters/Admins.

---

## 🛠️ Technology Stack

- **Frontend:** React, TailwindCSS, Lucide Icons, Vite
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL (Sequelize / pg)
- **AI Integration:** Groq Llama-3 Vision / OpenAI API
- **Deployment:** Render Web Services & Static Publishing

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v18 or higher)
- PostgreSQL Database

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Vijaysriv05/AI-Driven-Digital-loan-approval-workflow-with-eligibility-and-document-verification..git
   ```

2. **Backend Setup:**
   ```bash
   cd backend
   npm install
   npm start
   ```

3. **Frontend Setup:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
